<h1 align="center">Thor Corners</h1>

<p align="center">
  Light-weight, true-black rounded screen corners for <b>both</b> screens of the <b>AYN Thor</b>.<br>
  No ads, no tracking, no internet access, and touches always pass through.
</p>

The AYN Thor's main panel have hard square corners. The external display has small, tight corners. This app aims to fix this and make it more aesthetically pleasing.
(The bottom screen edge-curves are more aimed towards **Thor Black** users! - it blends into the edges)


This app is inspired by [Curvo: Round Screen Corners](https://play.google.com/store/apps/details?id=com.mobileservicezonex.cornering) and coded **from scratch** by Claude


## Features:
- Individual controls per screen
- Per app controls
- Corners are oled supported. (Pure black)
- The corners does not block touches or swipes, (big flaw from Curvo)
- Battery controls
- Starts on boot
